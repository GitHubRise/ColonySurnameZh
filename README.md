# Colony Surname ZH

给 RimWorld 1.6 的殖民者加上**中式姓名**，并新增一批**原版没有的关系**（旧识、事件、义亲、正/侧室、塑料闺蜜）。

- packageId：`local.colonysurnamezh`
- 依赖：Harmony（`brrainz.harmony`）
- 支持版本：1.6

## 功能

### 1. 中式姓名

- 人类殖民者生成时按比例换成「姓 + 名」，姓放 `Last`、名放 `First`，所以婴儿命名会继承姓氏。
- 姓名池在 `Data/Names/*.txt`，一行一个，可直接编辑：
  - `Surnames.txt`：约 160 个单姓 + 25 个复姓（欧阳、司马、上官、诸葛、独孤等）
  - `MaleGiven.txt` / `FemaleGiven.txt`：男女名池（单字，约 227 / 222 个，生成时随机拼 1–2 字）
  - `UnisexGiven.txt`：中性名池（约 79 个单字）
  - `Nick.txt`：小名池（二狗、狗蛋、铁柱、小强、阿珍、老李……）
- 显示为「姓+名」；有小名时社交页显示「名 '小名' 姓」。
- 设置里可一键为现有玩家派系人口重命名。

| 朋友 | +10 | |
| 网友 | +8 | |
| 笔友 | +6 | |
| 工友 | +5 | |
| 邻居 | +6 | |
| 战友 | +18 | |
| 师父 / 徒弟 | +14 / +8 | 两个 Def 成对写入 |
| 冤家 | −18 | 负向，恋爱倾向 0.6 |

事件型：救命恩人 / 被救者、生死之交、主治医生 / 病人 / 前病人、病友、狱友、同谋、老师 / 学生、袍泽、牌友、酒友、室友、旅伴、仇人、结拜（兄弟/姐妹）、义兄/义妹。

义亲：义父/义母 ↔ 义子/义女，右键「认义亲」发起，年龄差 ≥16、非血亲/恋偶、双向好感 ≥20、每人义子女 ≤3。

婚配：正夫/正妻、侧夫/侧室、共夫/共妻；正/侧按最早一条配偶关系判定，离婚或死亡后自动递补。

塑料闺蜜：仅女女，表面 +2；每天 1% 撕破脸变成冤家（一方好感为负时 5%）。

派生：情敌（共享恋人）、同门（同一位老师），随恋情/师承实时变化。

### 3. 自动结拜

双向好感都 ≥60 并连续保持 5 天，自动结为结拜兄弟/姐妹并弹出消息；掉到 60 以下、分图、死亡或已有关系时计数清零。

## 设置

游戏内「选项 → Mod 选项 → Chinese Names & Relations」。**姓名与关系是两个独立页签**，互不共用。

- **姓名**：启用、中文名比例、命名范围（全部人类 / 仅玩家派系 / 仅人类种族）、小名概率、为现有人口重命名。
- **关系**：顶部是全局开关与旧识生成概率；下面按「旧识 / 事件 / 家庭 / 婚配 / 派生」五段列出全部 35 条关系，**每条关系一行参数组**：
  - 启用复选框：关闭后不再新增该关系（已有关系保留）；
  - 权重步进器（仅生成型的旧识关系）：决定新殖民者播种时被选中的相对概率；
  - 好感步进器（−40…+40）：立即写回该关系的 `opinionOffset`，影响社交页好感。
  - 规则段：自动结拜阈值（默认 60）与连续天数（默认 5）、塑料闺蜜开关、义亲开关/年龄差/好感/上限。
  - 「重置关系参数」恢复全部默认值。
- **婚配**：婚配制度（原版一夫一妻 / 一夫多妻 / 一妻多夫 / 两者皆可）、每人配偶上限（默认 3）、正/侧室标签开关、共夫/共妻开关、嫉妒念头开关、争宠事件概率（默认 3%）。
- **关于**：版本与已知限制。

## 构建与部署

```powershell
cd E:\RimWorld-WorkSpace\sources\ColonySurnameZh
.\build.ps1            # 编译到 Assemblies\ColonySurnameZh.dll
.\build.ps1 -Deploy    # 复制到游戏 Mods\ColonySurnameZh（需先退出游戏）
```

## 已知限制

- 同一名殖民者只有一个床位，多配偶不会自动加床。
- 原版社交页底层仍是「丈夫/妻子」，正妻/侧室只在社交关系行里改写标签。
- 关系 Def 的标签是中文硬编码，英文环境下也显示中文（设置页有英文 Keyed）。
- 旧识与事件型关系需要新生成/新加入的殖民者才会播种，老存档不会追溯补关系。
